# 2026-10-29

## 新增子项目 h3c-ops-agent（华三交换机批量运维 Agent）

需求：在 ops-manager 下新建子项目，能自动批量巡检华三交换机、配置标准团体名、自动接入 Zabbix 并监控、备份配置文件。

### 技术选型
- 依赖只用共享 venv 已有的 paramiko / requests / openpyxl，**没有引入 netmiko**，用 paramiko + invoke_shell 自己写 Comware 交互层（环境里 netmiko 未安装，少装一个依赖）
- 配置用 JSON（环境无 PyYAML），支持环境变量覆盖密码
- 包结构：`h3c_ops/{config,inventory,ssh,inspect,snmp,zabbix,backup,report,models,runner,cli}.py`，入口 `run.py`
- 命令：init / devices / inspect / snmp / zabbix / backup / full；默认预览，写操作需 `--apply`（+ 交互确认，`-y` 跳过）

### 关键实现决策
- 提示符正则由实际主机名动态生成（`<name>` / `[name-...]`），避免 `[Y/N]`、`[flash:/startup.cfg]` 被误判为提示符
- 主机名允许 `-`（`SW-Core-01` 这类很常见），login 若落在系统视图先 `return` 再识别
- 认证失败不重试（防账号锁定），只有网络类错误重试
- `save force` 只认回显**末尾**的提问，避免同一条回显里 `Continue? [Y/N]` 被应答两次
- 巡检可选命令（风扇/电源/温度/光模块）失败不记异常，部分型号不支持
- SNMP 幂等 + ACL 只补齐缺失规则；团体名用 `simple` 明文便于回读校验；不配写团体名
- Zabbix 先查后改，产出变更计划；同名主机 IP 不一致默认报冲突不覆盖；host.update 只做增量合并（组/模板/宏不丢）
- 备份：每次快照 + `latest.cfg` + unified diff + meta.json，保留 N 份；同秒多次备份自动加序号

### 验证
- `python -m unittest discover -s tests -t .` → 103 用例全绿，全部不依赖真实设备（SSH 层用假 channel 模拟）
- CLI 端到端：init / devices / full 预览 均跑通，生成 report.xlsx + summary.md + results.json + run.log

### 未验证
- 真实华三设备（无设备可连），SSH 层的分页、save 交互是按 Comware 回显规范模拟的
- Zabbix 真实 API（模板名、主机组需现场确认）

## h3c-ops-agent 迭代：按清单账号密码自动登录配团体名

需求：根据设备清单 + 账号密码，自动登录进去配置团体名（不满足于"每台都得先在 config.json 配好一套账号"）。

### 改动
- 新增 `h3c_ops/login.py`：凭据优先级 = 命令行 `--user/--password`（**排他，不再回落**）> 设备清单该行 > `credentials.candidates` 候选账号 > `credentials` 默认。
  网络类错误不换账号，认证失败才换；**同一账号只试一次**防锁定；用了备用账号会记告警进报告。
- `Device.credential_source` 标记凭据来源（设备清单 / 配置默认 / 清单+配置默认），`devices` 命令直接显示，能当场发现填错。
- `ssh.py` 重写 `elevate()`：`super 3` 是"问密码"的交互（不回提示符），改走 channel 原始读写，返回 `(ok, 说明)`；`open_session` 登录后自动提权，失败只告警。
  注意：`SUPER_OK` 只认 "now user privilege is"，因为"user privilege level is 3"也会出现在"已是 3 级无需提权"的提示里。
- `enter_config` 失败时明确提示"账号权限不足 → 补 super密码 或换账号"。
- 导入期把 paramiko **仍实现但默认不协商**的老算法追加到偏好末尾（`enable_legacy_algorithms`）。实测 paramiko 5.1.0 **已彻底移除 SHA-1 系 KEX 和 ssh-rsa**，只支持这些算法的 Comware V5 老固件无法连接，只能在报错里引导升级固件/用 `paramiko<3`。
- CLI 新增 `--user/--password/--secret`；`snmp` 执行前打印"计划"（账号、团体名、ACL 放行谁、清单覆盖项）；`snmp.read_community` 改为"配置或清单任一有即可"。
- 报告 xlsx「巡检汇总」新增「登录账号」列；`results.json` 增加 account / login_note / login_warnings。

### 验证
- 测试从 103 → **121 全绿**，新增 `test_login.py`（回落顺序、去重、排他、网络错误不换号、提权告警）、`test_runner.py`（凭据传递与结果落表）、`test_ssh.py` 补 5 个 super 提权交互用例
- 端到端：新环境 init → devices（显示凭据来源）→ snmp 预览 → `--apply -y --user admin --password ...` 均跑通（目标 IP 不可达，验证的是容错与报告）
